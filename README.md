# Каталог настільних ігор

Навчальний проєкт з курсу «Програмування веб-застосувань», варіант 4.

## Запуск

```
cd server
npm install
npm start
```

Після запуску сайт відкривається за адресою http://localhost:3000.

## Безпека (практикум 15)

**XSS.** Пошук `innerHTML`, `v-html` та `insertAdjacentHTML` по проєкту нічого не знайшов. Назва гри, яку вводить користувач, виводиться у Vue через `{{ title }}`, тобто як текст, тому рядок `<img src=x onerror="alert('XSS')">` показується звичайним текстом. Для перевірки назву тимчасово виводили через `v-html` (аналог `innerHTML`), і тоді спрацьовував alert. Після повернення `{{ title }}` рядок знову показується як текст.

**Роздача файлів сервером.** У практикумі 14 `express.static` роздавав увесь корінь проєкту, тому за адресою `/server/server.js` можна було прочитати код сервера, а також файли з `server/node_modules`. Тепер сервер віддає лише `index.html`, `css`, `js` і `assets`, а на інші шляхи повертає 404.

**localStorage та IndexedDB.** У localStorage зберігається лише прапорець `migrated` (і старий ключ `boardGames`, якщо він лишився з попередніх практикумів). В IndexedDB у сховищі `games` лежать назва, кількість гравців, тривалість, жанр, картинка та позначки owned і played. Чутливих даних там немає.

**Секрети.** У коді немає ключів API чи паролів, клієнт звертається лише до локального `/api/games`.

**HTTPS.** Застосунку потрібен Node-сервер, тому GitHub Pages не підходить. Для фінальної здачі обрано Vercel, який дає HTTPS за замовчуванням.
